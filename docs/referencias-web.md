# Referencias web — Indigo Estudio

Selección inicial para explorar tipografía grande, impacto visual y composición limpia. Son referencias de dirección, no diseños para copiar.

## Referencias principales elegidas

### [EVOL](https://evol.la/)

Es la referencia visual principal elegida para Indigo Estudio.

Elementos que orientarán el diseño:

- Tipografía protagonista a gran escala.
- Composición limpia y directa.
- Contraste fuerte entre fondo y texto.
- Ritmo vertical marcado.
- Movimiento integrado a la identidad.
- Mensajes cortos con presencia.
- Proyectos mostrados con fuerza visual.

La identidad de Indigo sumará color propio, lenguaje colombiano y una experiencia de audio.

### [TOORMIX](https://toormix.com/)

Es la referencia principal para el color y la composición modular.

Elementos que orientarán el diseño:

- Amarillo intenso con negro.
- Paneles grandes con esquinas redondeadas.
- Ilustraciones y formas gráficas en negro.
- Tipografía fuerte y compacta.
- Navegación pequeña, visible y flotante.
- Composición experimental, pero fácil de recorrer.

### [Socialmood](https://socialmood.com/)

Es la referencia principal para interacción, humor y sorpresas durante el recorrido.

Elementos que orientarán el diseño:

- Portada construida como un collage vivo.
- Cursor con personalidad y respuesta visual.
- Escenas que cambian mientras se hace scroll.
- Frases enormes combinadas con microtextos.
- Listas que reaccionan al pasar el cursor.
- Humor breve dentro de la navegación.
- Elementos persistentes que conectan todo el recorrido.

### Las más cercanas a la dirección actual

7. **Praxis:** minimalismo y composición.

## Primera dirección posible

**Portada:** frase gigante de 3 a 5 palabras.

**Proyectos:** imágenes grandes, título y categoría.

**Color:** amarillo y negro como combinación principal.

**Movimiento:** pocas transiciones, con intención.

**Texto:** una idea por bloque, siempre breve.

**Navegación:** slider vertical con secciones a pantalla completa.

**Intro:** pantalla minimalista inspirada en Unseen Studio, con frase corta y entrada con o sin audio.

Pendiente: elegir una o dos referencias complementarias.
