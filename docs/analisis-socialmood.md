# Análisis de referencia — Socialmood

Referencia: [socialmood.com](https://socialmood.com/)

Estado: referencia principal para interacción.

## Lectura general

Socialmood mezcla una estructura muy simple con momentos inesperados. La web se siente activa porque el cursor, el scroll, los textos y el color responden durante el recorrido.

La interacción funciona como parte de la personalidad, no como decoración aislada.

## Recorrido observado

### 1. Portada — Muy fuerte

- Nombre gigante ocupando casi toda la pantalla.
- Collage de imágenes pequeñas, memes y objetos encima de las letras.
- Mensajes mínimos: «Holi!» y dos enlaces breves.
- Cursor con halo y respuesta visual.

**Para Indigo:** usar un símbolo grande con piezas del trabajo flotando alrededor.

### 2. Presentación y servicios — Clara

- Frase de gran tamaño como argumento principal.
- Servicios en una línea pequeña debajo.
- Mucho espacio libre.
- Barra inferior persistente que sostiene la navegación.

**Para Indigo:** una frase gigante y máximo tres servicios visibles.

### 3. Listados interactivos — Muy útil

- Filas numeradas con títulos grandes.
- La fila activa cambia a amarillo.
- Flecha simple como invitación a abrir.
- Jerarquía clara sin tarjetas tradicionales.

**Para Indigo:** presentar proyectos como una lista gigante que revela una imagen al pasar el cursor.

### 4. Pausa interactiva — Memorable

- Una escena fija responde al avance del scroll.
- El texto central cambia paso a paso.
- Un resplandor amarillo crece sobre un fondo limpio.
- El humor recompensa a quien sigue explorando.

**Para Indigo:** crear una pausa breve entre proyectos con color, sonido y una frase colombiana.

### 5. Cierre — Claro

- Una última frase enorme cierra la idea del estudio.
- Contacto y ubicaciones aparecen debajo sin adornos.
- La identidad sigue presente hasta el final.

**Para Indigo:** cerrar con «¿Tienes una idea? Hagámosle.» y contacto directo.

## Qué adoptaremos

- Interacciones vinculadas al scroll.
- Cursor con respuesta visual en escritorio.
- Cambios de color entre escenas.
- Proyectos que reaccionan al pasar el cursor.
- Humor breve y lenguaje cercano.
- Elementos persistentes para orientar el recorrido.

## Reglas para Indigo

- Una interacción principal por escena.
- El proyecto siempre debe poder abrirse con facilidad.
- Las animaciones no retrasarán la navegación.
- El cursor especial se limitará a escritorio.
- En celular, las interacciones dependerán del scroll y el toque.
- Habrá una versión con movimiento reducido.
- El texto sobre fondos luminosos mantendrá contraste suficiente.

## Riesgos observados

- Algunos enlaces parecen intencionalmente ambiguos.
- El cursor personalizado puede ocultar textos pequeños.
- La escena amarilla tiene momentos de contraste bajo.
- Varias sorpresas seguidas pueden competir con los proyectos.
- El comportamiento en móvil y con teclado requiere revisión aparte.

## Síntesis para Indigo

**EVOL pone la escala. TOORMIX pone el color. Socialmood pone el juego.**
